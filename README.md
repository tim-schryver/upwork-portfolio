# Upwork Portfolio

Python examples by Tim Schryver that show how to handle retries and concurrent requests safely.

- [Signed Webhook Inbox](signed-webhook-inbox/) verifies HMAC signatures and stores incoming events in SQLite with duplicate detection.
- [Inventory Reservation API](inventory-reservation-api/) reserves stock atomically and handles duplicate checkout requests without overselling.

Each project includes local run instructions and a test suite. Both use the Python standard library.
